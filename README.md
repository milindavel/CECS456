# CECS456
## Natural Images CNN
I used Google Colab to create and run this project. I have provided both the notebook and python file version.

## Kaggle Setup
https://www.kaggle.com/datasets/prasunroy/natural-images/data
I used this Kaggle Natual Images dataset.
This project requires a Kaggle API token.
Create kaggle.json from your Kaggle account and upload it when prompted in Colab.

## How to Run
1. Upload kaggle.json
2. Run all cells from top to bottom
3. Dataset is downloaded automatically
4. Training and evaluation results will be reproduced
